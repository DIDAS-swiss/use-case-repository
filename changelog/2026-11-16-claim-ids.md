# 2026-11-16: Claims referenced by id (iteration 1)

## Added

- Every credential entry lists its claim ids in `claims:`, one per row of
  «Claims (indicative)», whose first column now holds the id. On I14Y the ids
  are the schema's attribute names (Beta-ID, residence confirmation); the eLFA
  uses the names of ASTRA's published schema; the others are proposed.
- Use-case entries can list `claims_needed` as `<credential-id>#<claim-id>`; a
  combination across credentials is several items. The draft script fills the
  «Claims needed» column of the «Credentials» table from it.
- *Check data*:
  - **error:** a `claims_needed` item for a credential not relied on;
  - **error:** a credential whose `claims` and table disagree;
  - **warning:** a claim id the credential does not list;
  - **warning:** two use cases with the same verifier, question and claims
    ("probably one use case");
  - **note:** claims no use case needs.

No use case is backfilled; the I14Y federation is unchanged.
