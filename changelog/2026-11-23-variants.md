# 2026-11-23: Variants

## Added

- `variant_of`: a use case names the use case it is a variant of, that is, the
  same verifier role and the same verifier question in another context. It is
  a field in the issue form (after *Downstream use cases*), a batch column, an
  entry field and a section in the links comment. The use-case page shows the
  link in both directions. *Check data* resolves the ids like the other
  relations, rejects a use case that names itself and warns when two name each
  other. The boundary check accepts a variant pair.
- `[variant]` after a reference in `external_refs` marks an entry of another
  list that describes a variant of the use case, for example
  `FB-EID-E21-001 [variant]`.

## Changed

- CONTRIBUTING.md (*Where one use case ends*), GOVERNANCE.md, intake/README.md
  and the entry template describe both.
