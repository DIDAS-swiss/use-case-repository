# 2026-11-06: Register button and project board

## Added

- A prominent **Register your use case** call to action: buttons at the top of the
  README, a highlighted box at the top of the site's home page, a button in the
  site navigation and at the end of the use-case list. All open the
  *Use-case candidate* form
- `PROJECT.md`: the project board as the entry point to the workflows, with its
  status flow, fields, views (intake, use cases, gap board, supply, sector,
  federation updates) and GitHub Projects' built-in automations, plus the steps
  to create it and the text for its README
- `project_url` in `_config.yml`, used by the site's *Project board* button

## Notes for review

- The project itself has to be created in the organisation's settings; the
  repository cannot create it. Until then the *Project board* buttons point to the
  organisation's project list
