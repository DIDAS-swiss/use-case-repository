# 2026-11-16: The source of each use case

## Changed

- The form field *Proposed on behalf of* is now **Source of the use case**. It
  moves up to directly after *Sources*, among the questions every submitter
  sees, and names who brings the use case: DIDAS, a member organisation, an
  authority, a company, or "individual". Bodies written with the earlier label
  still parse.
- The backlog page shows the source as a column and can filter by it.
- The batch column `proposed_by` fills the field, as before (all 128 current
  candidates: DIDAS).
