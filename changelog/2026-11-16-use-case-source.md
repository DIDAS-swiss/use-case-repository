# 2026-11-16: The source of each use case

## Changed

- The form field *Proposed on behalf of* moves up to directly after *Sources*,
  among the questions every submitter sees. Its description now says what it
  is: the source of the use case, the organisation it comes from (DIDAS, a
  member organisation, an authority or a company; empty for an individual).
- The source is published: the backlog page shows it as a column and can filter
  by it, a published use case shows it in its facts panel, and the use-case
  index has a column for it.
- The batch column `proposed_by` fills the field, as before (all 128 current
  candidates: DIDAS).
