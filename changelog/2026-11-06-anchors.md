# 2026-11-06: The use case as anchor: trust flows, patterns, I14Y schemas

## Added

- Use cases link what already exists for them: `trust_flows` (DIDAS Trust Flow
  Diagram Repository, `<sector>/<family>/<flow>`), `ifm_patterns` (DIDAS Industry
  Function Graph) and `implementations`. Credentials carry `schema_status`
  (`i14y`, `emerging` or `none`)
- The *Use-case candidate* form captures them: dropdowns for trust flows, Industry
  Function Graph patterns and the credential datasets on I14Y, plus fields for
  other flow diagrams, emerging schemas and implementations. The *Credential need
  / supply signal* form offers the I14Y datasets too
- `_data/trust-flows.csv`, `_data/ifm-patterns.csv` and
  `_data/i14y-credentials.csv`, copied from their sources by
  `scripts/sources_sync.py` and `scripts/i14y_sync.py`;
  `scripts/build_issue_form.py` writes them into the forms
- An *Anchors* section on every use-case page, and an
  [Anchors page](https://didas-swiss.github.io/use-case-repository/anchors.html)
  listing every trust flow, pattern and I14Y credential dataset with the use
  cases that point to it, and marking those without one
- The vaccination use case is anchored to Trust Flows `health/immunization/F-01`,
  `F-02`, `F-03` and `F-06` and to its implementation, digital-health_swiyu.
  Vehicle leasing points to the patterns `identity-verification` and
  `due-diligence-onboarding`; motor vehicle claims processing to
  `identity-verification`

## Changed

- The *Sync schemas from I14Y* workflow is now *Sync federated sources*
  (`federation-sync.yml`): it also refreshes trust flows, patterns and sectors,
  rebuilds the form choice lists, and proposes every change as one pull request
- The credentials index shows each credential's schema status

## Notes for review

- No trust flow models vehicle leasing or motor vehicle claims processing yet,
  and no Industry Function Graph pattern fits the vaccination journey or claims
  processing as a whole. The Anchors page lists these gaps
