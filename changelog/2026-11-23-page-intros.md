# 2026-11-23: Page introductions

- The introductions of the website pages follow the writing rules: what the
  page lists, where the data comes from and how it is updated, without
  unsupported claims. Rewritten: home (README.md and the start box), Anchors,
  Backlog, Use-case ids, Shared dependencies, Credentials.

  for the page's meta description and falls back to the site description.
