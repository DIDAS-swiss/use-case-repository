# Schemas federated from I14Y

Credential schemas published on [I14Y](https://www.i14y.admin.ch/), the Swiss
interoperability platform, cached here so that use cases and credential entries
can show them. I14Y is the authoritative source: everything in these folders is
generated by [`scripts/i14y_sync.py`](../../scripts/i14y_sync.py) and refreshed
by the *Sync federated sources* workflow, which proposes any upstream change as
a pull request.

| Credential | I14Y dataset | Publisher |
|---|---|---|
| [Beta-ID](beta-id/) | [`urn:vct:ch.admin.bcs.betaid`](https://www.i14y.admin.ch/de/catalog/datasets/urn:vct:ch.admin.bcs.betaid/description) | fedpol |
| [Residence confirmation](residence-confirmation/) | [`urn:vct:ch.egovernment.residency-permit-simple`](https://www.i14y.admin.ch/de/catalog/datasets/urn:vct:ch.egovernment.residency-permit-simple/description) | DVS |

To federate another credential, set `i14y_dataset` and `i14y_id` in its entry
(see [CONTRIBUTING.md](../../CONTRIBUTING.md#credentials-on-i14y)).
