# Use cases

Every published use case, with its lifecycle stage. None is published yet: all
use cases are candidates in the [backlog](../backlog.md) until a working group
has drafted them and a curator has merged the entry. To propose one, open a
[Use-case candidate](https://github.com/DIDAS-swiss/use-case-repository/issues/new?template=use-case-candidate.yml) issue.
The format is described in [CONTRIBUTING.md](../CONTRIBUTING.md).

Sectors follow **ISIC Rev. 5**, using the sector list of the
[DIDAS Industry Function Graph](https://github.com/DIDAS-swiss/industry-function-graph).
On the [published site](https://didas-swiss.github.io/use-case-repository/use-cases/)
the table can be filtered by sector; picking a section such as *L — Financial and
insurance activities* also finds the divisions and classes inside it.

Stages: `signal` → `candidate` → `qualified` → `active` → `maintained`, or
`deprecated`. See [GOVERNANCE.md](../GOVERNANCE.md#lifecycle-stages). Being
published here is not qualification, endorsement or production readiness; each
entry says how far its evidence goes (`evidence_status`). *Check data* fails when
this table and the files in this folder disagree, so the site cannot show an
entry this list does not have.

Candidates still in intake are the
[open `use-case` issues](https://github.com/DIDAS-swiss/use-case-repository/issues?q=is%3Aissue+is%3Aopen+label%3Ause-case).
